# R619 bounded native presentation experiment

Normal presentation remains the default. F8 runs normal / nonblocking-native / normal, each3seconds settling and12seconds measured, x4 and full-resolution inputs with native queue1 in every phase. Comparison exit/cancel/F9-off/focus loss restores normal presentation and the appropriate native latency setting. No new WPR or PIX recording is needed for this comparison.

The middle phase preserves ScriptHook's Present chain and adds DXGI_PRESENT_DO_NOT_WAIT to the original game swapchain only (not the XeFG swapchain). A native D3D11 fence is signaled and flushed after each experimental call. At the next native Present entry the previous fence must complete, bounding queued native work to the current frame plus the prior frame. CPU waiting is bounded to20ms in2ms slices and checks focus/output freshness. This fence does not replace any shared-colour final-use or native-to-FG synchronization.

Only a visible active FG output updated within100ms permits the experiment. DXGI_PRESENT_TEST and nonzero sync intervals pass through unchanged. Busy native presentation is treated as success only while that fresh FG output exists; the captured frame still reaches FG. Unsupported flags, missing ScriptHook capture callbacks, GPU gate timeout and genuine errors disable the experiment and abort its comparison. Flag/missing-callback fallback retries normal presentation; own capture is suppressed on retry if it already occurred. Genuine device errors propagate without retry or masking. Experiment counts and total gate wait appear in R619 log records.

The stable per-instance swapchain4 table preserves all41 methods, targets only the identified original GTA swapchain, and is installed only when the experimental phase begins. It is retained as a cheap pass-through after the phase, avoiding allocation/free races during Present. Source retargeting is refused; shutdown restores the original table if still owned. This is separate from the retired B318 per-call timing/profiling wrapper. The protected camera/temporal/freezing sources and installed FreezingFix DLL are unchanged.

Validation: Release build/source integrity passes (existing C4244 warnings). Hidden-window Arc A770 hardware smoke covers real D3D11 Present and fence use, simulated busy/unsupported paths, callback preservation and duplicate prevention, stale-output fallback, bounded timeout, device-error propagation and normal restoration. Comparison regression covers completion, automatic fallback, unsupported experiment, F8/F9/focus/timeout cleanup including cancellation in the experimental phase. Recorder parser and continuous success3/4, abort/start/save failure tests pass. Four installed runtime SHA256 hashes verified; INI and FreezingFix hashes unchanged, previous installation backed up under pre-R619-*.

This is a controlled experiment, not a claimed FPS fix. In-game driver/ScriptHook interoperability, performance and visual smoothness still require the F8 comparison. Reject or stop the experiment if it falls back or introduces artifacts; do not promote it to default on FPS alone.
