# Windows app download

Download the complete ready-to-run Windows package:

**[Zink-GTA-Enhancement-3.2.0-R655-Windows-x64.zip](https://github.com/RaSxBeasTz/GTA-5-LEGACY-Intel-XeSS-DLSS-4-4.5-and-5-with-Frame-Generation/releases/download/v3.2.0-R655/Zink-GTA-Enhancement-3.2.0-R655-Windows-x64.zip)**

The package is hosted as a GitHub Release asset because GitHub does not allow a 419 MB binary to be committed directly to the source tree.

After downloading:

1. Extract the complete ZIP to a normal folder.
2. Run `ZinkGTAUI.exe`.
3. The app automatically scans for GTA V Legacy and the installed GPUs.
4. Select Intel XeSS or NVIDIA RTX, choose settings, then use **Load GTA + mod**.

Do not run the executable from inside the ZIP. Keep the `Backend` and `Assets` folders beside `ZinkGTAUI.exe`.

The optional NaturalVision Evolved archive is not bundled. Download it from its official source and the app will detect it for automated installation.
